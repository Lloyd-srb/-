## 4c. ตั้งค่า Lobby กับ Match ให้อยู่เกมเดียวกัน (Milestone 8)

ผู้เล่นเข้าเกมที่ **start place** เสมอ ดังนั้น start place ต้องเป็น Lobby ส่วนห้องเกมเป็น place ที่สอง

1. เปิด Wolf Village ใน Studio → View → **Asset Manager** → Places → คลิกขวาที่ว่าง → **Add New Place** (place ใหม่นี้จะเป็นห้องเกม)
2. เปิดไฟล์ `out/WolfVillageLobby.rbxl` ใน Studio → File → **Publish to Roblox As…** → เลือกเกม Wolf Village → เลือก **start place** (place เดิม) → Overwrite
   (place เดิมเป็นแค่ Baseplate ที่ publish ไว้ตอนเริ่ม ถ้าคุณสร้างอะไรไว้ในนั้นแล้ว บอก Claude ก่อน)
3. เปิดไฟล์ `out/WolfVillage.rbxl` ใน Studio → Publish to Roblox As… → Wolf Village → เลือก **place ใหม่** จากข้อ 1 → Overwrite
4. ไปที่ create.roblox.com → Wolf Village → Places แล้วส่ง Place ID ของทั้งสอง place ให้ Claude
   (Claude จะใส่ใน `Config.Places`: LobbyPlaceId = start place, MatchPlaceId = place ใหม่)
5. ไม่ต้องเปิด "Allow Third Party Teleports" (ย้ายภายในเกมเดียวกัน) แต่การย้ายจะทำงานหลัง Publish แล้วเท่านั้น

การย้ายระหว่าง place ทดสอบใน Studio ไม่ได้ ต้องเทสต์ในเกมจริงที่ publish แล้ว (Play จากหน้าเว็บ)
