## 4b. โมเดลหมาป่า "Moonfang Stalker" (ไฟล์ FBX จาก Meshy)

ตรวจไฟล์แล้ว: 7,608 สามเหลี่ยม (ผ่านเกณฑ์ Roblox), มีกระดูก 56 ชิ้น, texture ฝังมาครบ 4 แผ่น
ท่าเดิน / วิ่ง 4 ขา / ตี / ขย้ำ / หอน ของเกมถูกลองกับโครงกระดูกของไฟล์นี้แล้วนอก Studio (ดูภาพ `docs/wolf_mesh_preview.png`)
ไฟล์ต้นฉบับเก็บไว้ที่ `assets/wolf/Moonfang_Stalker_mixamo.fbx`

ขั้นตอนนำเข้า (ต้องทำเองใน Studio เพราะ mesh ต้องอัปโหลดเข้าบัญชีของคุณ):
1. เปิดไฟล์ place ใน Studio
2. แท็บ Home (หรือ Avatar) → **Import 3D** → เลือกไฟล์ `Moonfang_Stalker_mixamo.fbx` → Import
3. หลังนำเข้า ดูใน Explorer: ใต้ MeshPart ของโมเดลต้องมี `Bone` ชื่อ `mixamorig:Hips`
   (ถ้าไม่มี Bone เลย แปลว่ากระดูกไม่ได้ถูกนำเข้า — แจ้ง Claude)
4. เปลี่ยนชื่อโมเดลเป็น `WolfMesh` → ใน ServerStorage สร้าง Folder ชื่อ `Imports` → ลากโมเดลเข้าไป
5. เปิด View → Command Bar แล้วพิมพ์บรรทัดนี้ กด Enter:
   `require(game.ServerStorage.Builders.BuildWolfMesh)`
   ในหน้าต่าง Output ต้องขึ้น `[BuildWolfMesh] done`
6. ตั้ง `Config.Debug.ForceRole = "Wolf"` แล้วกด Play รอถึงกลางคืน

ถ้าไม่ทำขั้นตอนนี้ เกมจะใช้หมาป่าทรงบล็อกที่สร้างจาก Part ตามเดิม (ไม่มีอะไรพัง)

สิ่งที่ต้องดูด้วยตาใน Studio (ตรวจนอก Studio ไม่ได้):
- หมาป่าหันหน้าไปทางเดียวกับที่เดิน ไม่เดินถอยหลัง
- ขนาดประมาณ 9 studs (สูงกว่าคนเกือบเท่าตัว) เท้าแตะพื้น
- ท่าวิ่ง 4 ขา เท้าอาจลอยจากพื้นเล็กน้อย — ปรับได้
- ตาไม่เรืองแสงเอง (เป็นสีเหลืองจาก texture) — ถ้าอยากให้เรือง Claude จะติดชิ้น Neon เพิ่มเมื่อเห็นตำแหน่งจริง

เรื่องสิทธิ์: ถ้าสร้างด้วยแผนฟรีของ Meshy โมเดลเป็นแบบสาธารณะ ต้องให้เครดิต Meshy และคนอื่นดาวน์โหลดไปใช้ได้ — โปรดตรวจเงื่อนไขในบัญชี Meshy ของคุณ

## ข้อจำกัดที่ควรรู้

- **Voice chat กับผี:** แชทข้อความถูกแยกตามกติกาแล้ว แต่ **เสียง** ยังไม่ได้แยก — คนที่ตายแล้วยังพูดบอกคนเป็นได้ว่าใครคือหมาป่า
  ทางเลือก: (ก) ปิด voice chat ไปก่อน, (ข) ให้ Claude ทำระบบแยกเสียงด้วย Audio API ใหม่ของ Roblox ในช่วง Polish (ต้องเทสต์หลายคนใน Studio),
  (ค) ยอมรับไว้ (เล่นกับเพื่อนที่ไว้ใจกัน)

- **ตัวตนของหมาป่า:** ตอนแปลงร่าง ร่างคนและป้ายชื่อถูกซ่อน ผู้เล่นปกติดูไม่ออกว่าใครเป็นหมาป่า
  แต่ตัวหมาป่ายังเป็นตัวละครของผู้เล่นคนนั้นในระบบ Roblox คนที่ใช้โปรแกรมโกงจึงอ่านชื่อเจ้าของตัวละครได้
  (เป็นข้อจำกัดของ Roblox เอง แก้ที่ฝั่งเกมไม่ได้ทั้งหมด)
- **คนที่ซ่อนอยู่:** ร่างจริงถูกย้ายไปเก็บไว้ไกลจากแมพ คนอื่น (รวมถึงโปรแกรมโกง) จึงดูไม่ออกว่าซ่อนอยู่จุดไหน

## 4c. ตั้งค่า Lobby กับ Match ให้อยู่เกมเดียวกัน (Milestone 8)

ผู้เล่นเข้าเกมที่ **start place** เสมอ ดังนั้น start place ต้องเป็น Lobby ส่วนห้องเกมเป็น place ที่สอง

1. เปิด Wolf Village ใน Studio → View → **Asset Manager** → Places → คลิกขวาที่ว่าง → **Add New Place** (place ใหม่นี้จะเป็นห้องเกม)
2. เปิดไฟล์ `out/WolfVillageLobby.rbxl` ใน Studio → File → **Publish to Roblox As…** → เลือกเกม Wolf Village → เลือก **start place** (place เดิม) → Overwrite
   (place เดิมเป็นแค่ Baseplate ที่ publish ไว้ตอนเริ่ม ถ้าคุณสร้างอะไรไว้ในนั้นแล้ว บอก Claude ก่อน)
3. เปิดไฟล์ `out/WolfVillage.rbxl` ใน Studio → Publish to Roblox As… → Wolf Village → เลือก **place ใหม่** จากข้อ 1 → Overwrite
4. ไปที่ create.roblox.com → Wolf Village → Places แล้วส่ง Place ID ของทั้งสอง place ให้ Claude
   (Claude จะใส่ใน `Config.Places`: LobbyPlaceId = start place, MatchPlaceId = place ใหม่)
5. ไม่ต้องเปิด "Allow Third Party Teleports" (ย้ายภายในเกมเดียวกัน) แต่การย้ายจะทำงานหลัง Publish แล้วเท่านั้น

การย้ายระหว่าง place ทดสอบใน Studio ไม่ได้ ต้องเทสต์ในเกมจริงที่ publish แล้ว (Play จากหน้าเว็บ)
