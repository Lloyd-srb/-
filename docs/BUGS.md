## ความเสี่ยงที่ยังตรวจไม่ได้ (ต้องดูใน Studio)

- โค้ดทั้งหมดยังไม่เคยรันใน Roblox Studio จริง — ทดสอบแค่ฝั่งเซิร์ฟเวอร์ด้วยตัวจำลอง และตรวจ type ของฝั่งผู้เล่น
- หลังคาบ้านอาจกลับด้าน (รูปตัว V)
- ท่าทางหมาป่า (โดยเฉพาะวิ่ง 4 ขา) และสคริปต์เตรียมโมเดล Meshy (`BuildWolfMesh`)
- ปุ่มบนจอมือถือ: ตอนนี้ให้ Roblox จัดตำแหน่งเอง (ข้อ 25) — ยังต้องดูบนเครื่องจริงว่าสวยและไม่ทับ
- เสียง: ยังไม่มี ID จึงยังไม่ได้ฟังจริง (ความดัง / ระยะได้ยินใน `Config.Audio` อาจต้องปรับ)
- ฟอนต์ FredokaOne / Gotham ไม่มีตัวอักษรไทย: Roblox จะใช้ฟอนต์สำรองให้เอง แต่หน้าตาอาจไม่เข้ากัน ต้องดูด้วยตา
- แถบเงิน (Lobby) และแถบเวลา (ห้องเกม) อยู่ด้านบนกลางจอ อาจชนปุ่มของ Roblox บนมือถือบางรุ่น
- ไอคอนบท: ภาพตัวอย่างวาดนอก Roblox ขอบมน / ความหนาเส้นในเกมอาจต่างเล็กน้อย
- ปุ่ม "กดค้าง" มองเห็นทะลุกำแพงได้ (ใช้ได้แค่ในบ้านตัวเอง แต่ "เห็น") เช่น หมอเห็นปุ่มชุบศพที่อยู่ในบ้านข้างๆ
- คลิกซ้ายของหมาป่า (โจมตี) อาจทำงานพร้อมกับการคลิกปุ่มบนหน้าจอ

- ข้อ 15–18, 21 เป็นโค้ดฝั่งผู้เล่น: ตรวจ type ผ่าน แต่ต้องลองใน Studio / มือถือจริง

## ข้อจำกัดที่รู้อยู่แล้ว

- Voice chat ยังไม่แยกคนเป็นกับผี — คนตายยังพูดบอกคนเป็นได้ (รอเจ้าของเกมตัดสินใจ: OWNER_TODO ข้อ 56)

- คนใช้โปรแกรมโกงอ่านได้ว่าตัวหมาป่าเป็นของผู้เล่นคนไหน (ข้อจำกัดของ Roblox)
- คนใช้โปรแกรมโกงยังวิ่งเร็วเกิน / วาร์ปข้ามแมพได้ (เกมกันแค่การทะลุเข้าบ้านที่ปิดประตู ข้อ 29) — ดูคำถามข้อ 84
- ข้อมูลว่าใครตาย "ตอนไหน" ถูกส่งให้ทุกเครื่องทันที (ใช้แสดงรายชื่อคนเป็น/ผี) — ผู้เล่นปกติไม่เห็นบนจอ แต่โปรแกรมโกงอ่านได้
