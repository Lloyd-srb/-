# Wolf Village — รายงานบั๊ก

## แก้แล้ว (มีทดสอบกันไม่ให้กลับมา: `tests/BugFixes.spec.luau`)

| # | บั๊ก | ผลกระทบ | แก้อย่างไร |
|---|---|---|---|
| 1 | กด "ค้น" / "ซ่อน" ได้ทะลุกำแพงบ้าน | หมาป่ายืนหลังบ้าน ค้นเตียงข้างในได้โดยไม่ต้องพังประตู | ต้องยืนอยู่ในบ้านหลังนั้นเท่านั้น |
| 2 | ระบบ Streaming ของ Roblox อาจไม่โหลดบ้านรอบตัวคนที่ซ่อนอยู่ | คนที่ซ่อนเห็นจอว่าง / เส้นขอบของคนที่อยู่ไกลไม่ขึ้น | ปิด Streaming (แมพเล็ก ไม่จำเป็น) และให้จุดซ่อนเป็นจุดโหลดแทน |
| 3 | กดปุ่ม Reset ตัวละคร | ผู้เล่นค้างสถานะ "ยังมีชีวิต" แต่ไม่มีตัว ตลอดเกม | ปิดปุ่ม Reset และถ้าตัวละครตายเองจะได้ร่างใหม่ที่เดิม เลือดเท่าเดิม (กันโกงเติมเลือด) |
| 4 | ชื่อเหนือหัวอาจมองทะลุกำแพงได้ | ตอนกลางคืนรู้ว่าใครอยู่บ้านไหน | ตั้งให้ชื่อถูกกำแพงบัง |
| 5 | ศพหมาป่ากลับเป็นร่างคนตอนเช้า | ทุกคนรู้ทันทีว่าใครเป็นหมาป่า | ศพหมาป่าคงเป็นหมาป่า |
| 6 | คนตายยังลากศพตัวเองได้ | ศพเลื่อนไปมา / โกงได้ | เซิร์ฟเวอร์ควบคุมศพแทน |
| 7 | ปุ่ม Debug ตีประตู (F) ชนกับไฟฉาย (F) | เทสต์ใน Studio แล้วงง | ย้ายปุ่ม Debug ไปที่ G |
| 8 | (พบระหว่างเขียน M4) ประตูยังไม่มีค่า HP / สถานะจนกว่าจะถึงคืนแรก | ปุ่มเสริมประตูวันแรกทำงานผิด | ตั้งค่าตั้งแต่เริ่มเกม |
| 9 | (พบระหว่างเขียน M3) ลูกหมาป่าที่โตแล้วยังถูกบอกว่าเป็นชาวบ้าน | จอแสดงบทผิด | แก้แล้ว |

## ความเสี่ยงที่ยังตรวจไม่ได้ (ต้องดูใน Studio)

- โค้ดทั้งหมดยังไม่เคยรันใน Roblox Studio จริง — ทดสอบแค่ฝั่งเซิร์ฟเวอร์ด้วยตัวจำลอง และตรวจ type ของฝั่งผู้เล่น
- หลังคาบ้านอาจกลับด้าน (รูปตัว V)
- ท่าทางหมาป่า (โดยเฉพาะวิ่ง 4 ขา) และสคริปต์เตรียมโมเดล Meshy (`BuildWolfMesh`)
- ปุ่มบนจอมือถือ (ContextActionService) อาจซ้อนกันเมื่อมีทั้งปุ่มบทและปุ่มหมาป่า
- คลิกซ้ายของหมาป่า (โจมตี) อาจทำงานพร้อมกับการคลิกปุ่มบนหน้าจอ

## ข้อจำกัดที่รู้อยู่แล้ว

- คนใช้โปรแกรมโกงอ่านได้ว่าตัวหมาป่าเป็นของผู้เล่นคนไหน (ข้อจำกัดของ Roblox)
- ถ้าผู้เล่นจาก Lobby มาไม่ครบ 12/6 คน ห้องจะรอไปเรื่อยๆ — จะใส่เวลาหมดรอตอนทำ Lobby (Milestone 8)
