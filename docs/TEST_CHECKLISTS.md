# Wolf Village — Checklist สำหรับเทสต์ใน Studio

ทุกข้อด้านล่าง **ยังไม่เคยถูกเทสต์ใน Roblox Studio จริง** — ผ่านแค่การทดสอบจำลองนอก Studio
(กติกาและลำดับเหตุการณ์ฝั่งเซิร์ฟเวอร์) ส่วนที่เป็นภาพ, UI และฝั่ง client ต้องดูด้วยตาใน Studio

## ก่อนเทสต์

1. Game Settings → Avatar → Avatar Type = **R6**
2. เทสต์คนเดียวได้: ใน Studio ระบบ Debug จะเปิดเอง และเติม Bot ให้ครบ 12 คน
3. อยากให้เวลาเดินเร็ว: แก้ `Config.Debug.TimerScale` เป็น `0.1` (ทุกตัวจับเวลาสั้นลง 10 เท่า)
4. อยากเป็นบทไหน: แก้ `Config.Debug.ForceRole` เช่น `"Wolf"`

## Milestone 1 — แมพ

- [ ] บ้าน 12 หลังล้อมลานกลาง ประตูหันเข้าหาโต๊ะประชุม มีเลขบ้านเหนือประตู
- [ ] หลังคาเป็นทรงจั่วปกติ (ถ้าเป็นรูปตัว V ให้แจ้ง — แก้ได้บรรทัดเดียว)
- [ ] ในบ้านมีเตียง (มีช่องว่างใต้เตียง), ตู้เสื้อผ้า, พรม, โคมไฟ
- [ ] ยืนนอกบ้านมองหน้าต่าง: ทึบ มองไม่เห็นข้างใน / เดินเข้าไปในบ้าน: หน้าต่างบ้านนั้นใสขึ้น มองออกมาเห็นข้างนอก
- [ ] หลังบ้านทุกหลังมีแปลงผัก
- [ ] รั้วล้อมหมู่บ้าน มีประตูทางออก 4 จุด เดินออกไปป่าได้
- [ ] ป่ามีต้นไม้กระจายอยู่ เดินไปสุดขอบแล้วชนกำแพงล่องหน ข้างหลังเป็นป่าทึบมืด
- [ ] กลางวันสว่างสดใส

## Milestone 2 — วงจรเกมหลัก

กด Play (คนเดียวก็ได้)

- [ ] ขึ้นช่วงเลือกบท ~30 วินาที แล้วขึ้นชื่อบทของตัวเองกลางจอ และมุมซ้ายบน
- [ ] วันที่ 1 นับถอยหลัง 3:00 — กระดิ่งบนโต๊ะประชุมกดไม่ได้
- [ ] หมดเวลา: ขึ้นข้อความแดง "Full moon in 10 seconds" นับถอยหลัง
- [ ] เข้ากลางคืน: ท้องฟ้ามืด มีหมอกดำระยะไกล โคมไฟติด, ตัวเราถูกวาปเข้าไปในบ้านหลังหนึ่ง ประตูปิด มีหลอดเลือดเหนือประตู
- [ ] (ถ้าเป็นหมาป่า) ถูกวาปไปกลางลานแทน และไม่มีปุ่มเปิดประตู
- [ ] ยืนในบ้านใกล้ประตู: มีปุ่ม "เปิดประตู" (กด E ค้าง) → ประตูเปิดออกด้านนอก และปิดคืนไม่ได้
- [ ] ปุ่ม Debug "[Debug] ตีประตู" (ปุ่ม F ที่ประตู): กด 5 ครั้ง หลอดเลือดลดทีละ 1/5 แล้วประตูหายไป
- [ ] เช้าวันที่ 2: ถูกวาปมายืนหน้าบ้าน, ขึ้นข้อความแดง "You're safe... for now...", ประตูที่ถูกตีแตกมีไม้ปะซ่อมให้เห็น
- [ ] ถ้าอยู่ในป่าตอนเข้ากลางคืน: ไม่ถูกวาปเข้าบ้าน และเช้าก็ไม่ถูกวาป
- [ ] วันที่ 2 ผ่านไป 3 นาที: ขึ้นข้อความว่ากดเรียกประชุมได้ → กด E ค้างที่กระดิ่ง → นับถอยหลัง 1 นาที
- [ ] เริ่มประชุม: ทุกคนถูกวาปมายืนล้อมโต๊ะ เดินไม่ได้, หน้าโหวตเด้งขึ้น มีรูปหน้าและชื่อครบทุกคนที่ยังไม่ตาย
- [ ] กดเลือกคน: มีเงาสีเทาใต้ชื่อ 1 เงา → กดยืนยัน: เงาเป็นสีฟ้า และเปลี่ยนใจไม่ได้
- [ ] กดเลือกตัวเอง: ไม่เกิดอะไรขึ้น
- [ ] หมดเวลาประชุม: ขึ้นผล "... ถูกไล่ออกจากหมู่บ้าน" (ไม่บอกบท) → นับ 10 วินาที → เข้ากลางคืนที่ 2
- [ ] ไม่มีใครกดกระดิ่งจนหมดเวลากลางวัน: ถูกบังคับประชุมเอง
- [ ] ไม่มีใครโหวต: ไม่มีใครถูกไล่
- [ ] โหวตไล่หมาป่าออก: ขึ้นข้อความตอนจบ "Everyone lived happily ever after."
- [ ] (ตั้ง ForceRole = "Fool") โดนโหวตออก: ขึ้น "The fool laughs last."

## Milestone 3 — ฝ่ายหมาป่า

ตั้ง `Config.Debug.ForceRole = "Wolf"` แล้วกด Play คนเดียว — Bot มีร่างเป็นหุ่นยืนนิ่งให้ไล่ตีได้

**โมเดล (ดูใน Explorer → ServerStorage → Rigs → Wolf ลากมาวางใน Workspace เพื่อดู)**
- [ ] หมาป่าทรงบล็อกสีเทา ตาเหลืองเรืองแสง ไหล่ใหญ่ มีกรงเล็บ สูงกว่าคนชัดเจน
- [ ] Pup คือตัวเดียวกันแต่เล็กกว่า (60%)

**กลางคืน (เป็นหมาป่า)**
- [ ] เข้ากลางคืน: ตัวเรากลายเป็นหมาป่าที่กลางลาน ร่างคนและป้ายชื่อหายไป เดินเร็วขึ้น
- [ ] ยืนนิ่ง / เดิน: โมเดลขยับ (หายใจ / แกว่งแขนขา) ไม่แข็งทื่อ
- [ ] คลิกซ้าย (หรือปุ่ม Attack บนมือถือ): มีท่าตี ตีได้วินาทีละครั้ง
- [ ] ตีประตูบ้าน 5 ครั้ง: หลอดเลือดลดจนประตูแตก เดินเข้าบ้านได้ (ตัวไม่ติดประตู)
- [ ] ตี Bot ตัวแรกของคืน: Bot **ไม่ตาย** (กลายเป็นลูกหมาป่า) — ตีตัวถัดไป: ตายทันที ล้มนอนอยู่ตรงนั้น
- [ ] ตีผ่านกำแพงไม่โดน, หันหลังให้เป้าหมายแล้วตีไม่โดน
- [ ] กด Q (Sniff): คนที่อยู่นอกบ้านมีเส้นขอบ 3 วินาที — กดซ้ำภายใน 30 วินาทีไม่เกิดอะไร
      (บนมือถือปุ่มจะมีเลขนับคูลดาวน์ / บน PC ยังไม่มีตัวเลขคูลดาวน์บนจอ จะเพิ่มตอนทำ UI)
- [ ] กด Shift (Sprint): วิ่งเร็วมากและเป็นท่าวิ่ง 4 ขา 5 วินาที — ถ้าฆ่าระหว่างนี้ ตัวหยุดเล่นท่าขย้ำ ~3 วินาที
- [ ] มี Bot ไปอยู่ในป่า (นอกรั้ว): เห็นเส้นขอบสีแดงรอบตัวมันตลอด
- [ ] ที่เตียง/ตู้ในบ้าน: มีปุ่ม "ค้น" (กด E ค้าง 1 วิ)
- [ ] เช้า: กลับเป็นคน ยืนหน้าบ้าน ขึ้นข้อความเยาะเย้ยสีแดง (เพราะมีคนตาย)

**กลางคืน (เป็นคน — ตั้ง ForceRole เป็น "Villager")**
- [ ] ในบ้าน: ที่เตียง/ตู้มีปุ่ม "ซ่อน" → กดแล้วกล้องย้ายไปอยู่ในจุดซ่อน มีปุ่ม "ออกมา"
- [ ] กดออกมา: กลับมายืนในบ้าน และซ่อนใหม่ได้

**ต้องเทสต์หลายคน (Test → Clients and Servers, 2–3 คน)**
- [ ] คนที่ไม่ใช่หมาป่า **ไม่เห็น** เส้นขอบใดๆ และไม่เห็นปุ่มสกิลหมาป่า
- [ ] หมาป่าค้นจุดที่มีคนซ่อน: คนนั้นเด้งออกมา และซ่อนอีกไม่ได้จนเช้า
- [ ] คนที่โดนกัดคนแรก: จอขึ้นว่าเป็นลูกหมาป่า กลายเป็นหมาป่าตัวเล็ก ต้องตี 2 ครั้งคนถึงตาย กด Q หอนได้
- [ ] ฝ่ายหมาป่าเห็นชื่อฝูงที่มุมซ้ายบน คนอื่นไม่เห็น
- [ ] โหวตไล่หมาป่าออกโดยที่ลูกหมาป่ายังอยู่: เกมไม่จบ และอีก 2 คืนลูกหมาป่ากลายเป็นหมาป่าเต็มตัว

## Milestone 4 — บทบาท

ใน Studio ทุกบทปลดล็อกให้อัตโนมัติ (`Config.Debug.UnlockAllRoles`) อยากลองบทไหนตั้ง `Config.Debug.ForceRole` เป็นชื่อบทนั้น
อยากลองโหมด Turbo ตั้ง `Config.Debug.Mode = "Turbo"`

**หน้าเลือกบท**
- [ ] กด Play: ขึ้นหน้าเลือกบท มีครบ 10 บทพร้อมคำอธิบาย เลือกได้ 3 บท ตัวนับขึ้น "เลือกแล้ว 3/3" แล้วมีปุ่มยืนยัน
- [ ] กดยืนยัน: ขึ้น "รอผู้เล่นคนอื่น..." — ถ้าเล่นคนเดียว เกมเริ่มทันที
- [ ] ตั้ง `UnlockAllRoles = false`: บทที่ยังไม่มีเป็นสีจาง บอกว่า "ยังไม่มีบทนี้" หรือ "ต้องเลเวล X" เลือกไม่ได้ (ผู้เล่นใหม่มี 3 บทฟรี จะถูกเลือกให้อัตโนมัติ)
- [ ] ไม่กดอะไรเลย: หมดเวลาแล้วได้บทสุ่มจากที่มี

**ความสามารถ (ตั้ง ForceRole ทีละบท แล้วลองกับ Bot)**
- [ ] นายอำเภอ: กด R ยิงไปที่เมาส์ เห็นลำแสงสั้นๆ, คนที่โดนมีดาวเหนือหัวและเดินไม่ได้ 5 วินาที, ยิงได้วันละ 1 คืนละ 1 (ปุ่มบอกจำนวนที่เหลือ)
- [ ] ฆาตกร: กด R แทงคนตรงหน้าตายทันที วันละ 1 คืนละ 1, แทงลมไม่เสียสิทธิ์
- [ ] ผู้หยั่งรู้: กลางคืนกด Q เห็นทุกคนเป็นเงาขาวทะลุกำแพง 5 วินาที คืนละครั้ง (กลางวันกดไม่ได้)
- [ ] บอดี้การ์ด: กด Q พุ่งไปข้างหน้า ทะลุคนอื่นได้ ชนกำแพงแล้วหยุด, คูลดาวน์ 30 วินาที
- [ ] หลวงพ่อ: กลางวันกด Q ขึ้นรายชื่อคน เลือกได้ 1 คน (รวมตัวเอง) ขึ้นข้อความ "คุณให้พร ... แล้ว"
- [ ] วิศวกร: เดินไปที่ประตูบ้านหลังไหนก็ได้ มีปุ่ม "เสริมประตู" (กด R ค้าง) → ประตูกลายเป็นเหล็ก, กลางคืนหลอดเลือดยาวขึ้นเท่าตัว, กลางวันกับกลางคืนอย่างละครั้ง
- [ ] หมอ: ศพของคนที่ตายตอนกลางคืนมีปุ่ม "ชุบชีวิต" (กด E ค้าง 3 วินาที) → ศพลุกขึ้นมามีชีวิต, ทั้งเกมชุบได้ครั้งเดียว
- [ ] ชาวบ้าน: กด F เปิด/ปิดไฟฉาย (ลองตอนกลางคืน)
- [ ] หัวหน้าหมู่บ้าน: ในหน้าโหวต โหวตแล้วได้ 2 เงา, คะแนนเสมอแล้วฝั่งที่หัวหน้าโหวตชนะ ขึ้น "Ahem!"
- [ ] คนบ้า: ไม่มีปุ่ม (ชนะเมื่อถูกโหวตไล่)
- [ ] Turbo: 6 คน ทุกคนมีบทพิเศษไม่ซ้ำกัน ไม่มีชาวบ้าน

**ต้องเทสต์หลายคน**
- [ ] ปุ่ม "ชุบชีวิต" เห็นเฉพาะหมอ, ปุ่ม "เสริมประตู" เห็นเฉพาะวิศวกร
- [ ] เงาขาวของผู้หยั่งรู้ คนอื่นไม่เห็น
- [ ] หมาป่าตีคนที่ได้รับพร: ไม่ตาย ทั้งสองฝ่ายขึ้นข้อความ "การโจมตีถูกกันไว้!" ตีอีกครั้งตายตามปกติ
- [ ] นายอำเภอยิงฆาตกร: ฆาตกรตายทันที

### สิ่งที่ยังไม่มี (จะมาใน milestone ถัดไป)

หน้าเลือกบทและความสามารถของบท (4), ภารกิจ/ไอเทม (5), ผีและแชท (6),
Scoreboard และรางวัล (7), Lobby (8), ระบบเซฟและร้านค้า (9), เสียง (10)
— คนที่ตาย/ถูกไล่ตอนนี้ยังไม่เป็นผี (คนตายกล้องค้างอยู่ที่ศพ)
— หมอชุบเพิ่มด้วย First aid, ปืนจากกล่อง และไฟฉายแบบไอเทม มาพร้อมระบบไอเทม (5)
— ระบบซื้อบท / เลเวลจริง มาใน (9): ตอนนี้ทุกคนเริ่มเลเวล 1 มี 3 บทฟรี (ยกเว้นใน Studio ที่ปลดล็อกหมด)
